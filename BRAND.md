# Veil Arena brand kit

## The idea in one line

The competition is public. The winning strategy is not.

Veil Arena looks like a live tournament broadcast printed on security paper. It combines the tension of a scoreboard with the exactness of an evidence register.

## Identity

The canonical mark remains a split `V` inside an ink square. The vermilion stroke is the sealed strategy. The paper stroke is the disclosed result. The ink cut between them is the execution boundary.

The visual wordmark is `VEIL ARENA` as two uppercase words. `VEIL` carries the base weight and `ARENA` carries the heavier weight. The product name is `Veil Arena` in prose. Do not write `VeilAP`, `VEILAP`, or use `V/` as an alternate mark on new surfaces.

The mark may stand alone. The wordmark must keep clear space equal to half the mark's height. Use the same square mark for the favicon, navigation, arena broadcast, and social assets. Do not recolor, stretch, rotate, round, shadow, or place it on a busy image.

Canonical source asset: `public/brand/veilap-mark.svg`. Rename the asset only when every importing surface can move in one verified change.

## Color

| Token | Value | Role |
| --- | --- | --- |
| Ink | `#191915` | Arena ground, sealed records, and primary type |
| Security paper | `#e9e1d1` | Main broadcast field |
| Clean paper | `#f3eddf` | Leaderboard and receipt surfaces |
| Quiet text | `#5d5b52` | Supporting copy and annotations |
| Rule | `#9e998c` | Brackets, tables, and evidence dividers |
| Signal | `#ee5736` | Live match state, selected rank, and revealed evidence |
| Verified | `#264b3a` | Valid receipt and settled state only |

Signal vermilion is the single product accent. Use it for the live competition signal and the one selected disclosure. It is not decorative chrome.

## Type

- Display: Newsreader Variable for tournament headlines, rank, and editorial emphasis.
- Body: Manrope Variable for product copy, navigation, and controls.
- Verifiable identifiers: IBM Plex Mono with Cascadia Mono and Consolas fallbacks.

Use monospace only for commitments, agent IDs, match IDs, engine versions, receipt states, and chain identifiers.

## Layout

- Hard one-pixel rules and square panels.
- Tables use tabular figures and visible column structure.
- The Arena and Leaderboard switch is the primary interaction.
- A live match grid can be dense. Explanatory sections keep generous space.
- Hard offset shadows appear only on the main broadcast surface and proof inspector.
- No cards with soft radius, glass panels, neon gradients, particles, or casino imagery.

## Motion

Motion reports competition state:

- match progress advances in measured steps;
- one live marker pulses while a preview match runs;
- leaderboard rows change position only when the underlying score changes;
- the selective reveal opens after a result settles.

Every motion path must keep the final state when reduced motion is requested.

## Voice

Short, competitive, and exact. State what remains sealed, what becomes public, and what the receipt proves. Never claim that the operator cannot read strategies in the trusted-backend version.

Right: "The public sees the result. Competitors never receive the strategy."

Wrong: "Your strategy is private forever."
